\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{md__r_e_a_d_m_e_autotoc_md2}
This project simulates {\bfseries{network traffic}} on an {\itshape Autonomous System (AS)}-\/level topology and applies a {\bfseries{Graph Convolutional Network (GCN)}} model to learn and predict node-\/level properties such as network load, delay, or congestion.

The system uses\+:
\begin{DoxyItemize}
\item {\bfseries{Py\+Torch Geometric (PyG)}} for graph processing ~\newline

\item {\bfseries{NetworkX}} for graph analysis and routing simulation ~\newline

\item A real-\/world dataset {\ttfamily tech-\/as-\/topology.\+edges} describing AS-\/level connectivity
\end{DoxyItemize}

\DoxyHorRuler{0}
\hypertarget{md__r_e_a_d_m_e_autotoc_md4}{}\doxysection{\texorpdfstring{Features}{Features}}\label{md__r_e_a_d_m_e_autotoc_md4}
Load {\ttfamily .edges} topology files and build Py\+Torch Geometric graph objects ~\newline
 Construct node features and edge weights for graph learning ~\newline
 Implement and train a {\bfseries{2-\/layer GCN model}} for node-\/level prediction ~\newline
 Perform dummy training (regression on random targets) ~\newline
 Display graph structure, training progress, and model output ~\newline
